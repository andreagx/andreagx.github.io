# andreagx.github.io
Blog tecnico di Andrea Gallazzi, realizzato con Hugo e PaperMod

## Riferimenti

- [Blog pubblicato](https://andreagx.github.io/)
- [Statistiche — Cloudflare Web Analytics](https://dash.cloudflare.com/?to=/:account/web-analytics)

Per consultare le statistiche, accedi con il tuo account Cloudflare e seleziona il sito **andreagx.github.io**. Il collegamento apre la sezione Web Analytics; le statistiche richiedono accesso all’account.

L’integrazione del blog utilizza la variabile GitHub Actions `CLOUDFLARE_WEB_ANALYTICS_TOKEN`.
